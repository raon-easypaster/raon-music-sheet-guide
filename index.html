🚪 시작하기

앱 설치 없이 휴대폰·태블릿·컴퓨터의 인터넷 브라우저에서 바로 씁니다.

  1. 앱 열기 — 맨 위 🎵 앱 바로가기를 누르거나 raon-music-sheet.vercel.app 에 접속합니다.
  2. 회원가입 — 처음이라면 계정이 없어요 → 회원가입을 누르고 이메일과 비밀번호(6자 이상)를 입력합니다.
  3. 로그인 — 이미 가입했다면 이메일과 비밀번호를 넣고 로그인을 누릅니다.
비밀번호 보기 — 비밀번호 칸 오른쪽의 보기를 누르면 입력한 글자를 확인할 수 있습니다. 휴대폰에서 오타가 잦을 때 유용합니다. 다른 사람 앞에서는 숨기기로 바꿔 두세요.
휴대폰 홈 화면에 두기 — 아이폰은 Safari의 공유 버튼 → 홈 화면에 추가, 안드로이드는 Chrome 메뉴 → 홈 화면에 추가를 누르면 앱처럼 바로 열 수 있습니다.

🗂️ 작업 공간 (개인 / 팀)

곡과 콘티는 어느 공간에 있느냐에 따라 누가 볼 수 있는지가 정해집니다.

작업 공간누가 보나요언제 쓰나요
내 개인 공간나만개인 연습용 곡, 아직 팀에 공개하기 전의 콘티
팀: (팀 이름)그 팀의 팀원 모두주일 예배 콘티, 찬양팀이 함께 쓰는 곡
  1. 화면 맨 위 작업 공간에서 내 개인 공간 또는 팀: 라온 찬양팀 처럼 원하는 공간을 고릅니다.
  2. 고른 공간의 곡과 콘티만 보이고, 새로 만드는 곡·콘티도 그 공간에 저장됩니다.
  3. 마지막에 고른 공간은 다음에 들어와도 그대로 열립니다.
찬양팀 곡은 꼭 팀 공간에! 팀원과 함께 쓸 곡을 개인 공간에 넣으면 다른 팀원에게 보이지 않습니다. 곡을 추가하기 전에 맨 위 작업 공간이 팀으로 되어 있는지 확인하세요.

🎵 곡 목록 · 곡 추가

곡 추가하기

  1. 곡 목록 탭에서 곡 제목(필수)과 아티스트/원곡자를 입력합니다.
  2. 키 선택(C, D, Em …), BPM, 카포를 고릅니다.
  3. ▼ 링크·악보 펼치기를 누르면 아래 칸이 나옵니다.
    • YouTube URL — 예배곡 영상 주소
    • MR / 반주 URL
    • 악보 이미지 — 📷 악보 사진 올리기를 누르면 휴대폰으로 바로 찍거나 앨범에서 고를 수 있습니다. 사진은 교회 구글 드라이브 폴더에 저장되고 주소가 자동으로 채워집니다. 인터넷에 있는 악보 이미지 주소를 직접 붙여 넣어도 됩니다.
    • 악보 PDF URL — 인터넷에 올라가 있는 PDF 악보의 주소
    • 송폼 구조 — 예: Intro - Verse - Chorus - Bridge
    • 메모 — 연주 포인트, 전조 등
  4. 곡 저장을 누릅니다.
악보 찾기 — 곡 제목을 입력하고 제목 칸 옆 🔍 구글을 누르면 "곡 제목 악보"로 구글 검색이 바로 열립니다.
사진 올리기 팁 — 큰 휴대폰 사진은 자동으로 알맞은 크기로 줄여서 올립니다. 사진을 올린 뒤 꼭 곡 저장(수정 중이면 저장)을 눌러야 반영됩니다. 이미 다른 사진이 있으면 새 사진으로 바뀝니다.
교회가 사용 권한을 가진 악보만 올려 주세요. 출판사·저작권자의 허락 범위를 넘는 악보를 올리면 안 됩니다. (저작권 안내)
PDF 악보·인터넷 이미지 — PDF는 파일을 올리는 대신 주소(URL)를 넣습니다. 이미지 주소는 브라우저 주소창에 넣었을 때 그림이 바로 열리는 주소여야 합니다.

곡 찾기 · 보기 · 고치기

  • 검색 — 제목·아티스트·코드 검색 칸에 일부만 입력해도 찾아 줍니다. 예: 손경민, Em
  • 정렬 — 등록순 · 제목순 · 아티스트순 · 코드순 · BPM순
  • 보기 — 악보·영상·MR·송폼·메모를 한 화면에서 봅니다.
  • 수정 — 곡 정보를 고칩니다. 팀 곡은 팀원 누구나 고칠 수 있습니다.
  • 삭제 — 개인 곡은 본인이, 팀 곡은 팀장만 지울 수 있습니다. 팀원에게는 팀 곡의 삭제 버튼이 보이지 않습니다.
  • 팀 공간에서는 곡마다 등록: 이메일이 표시되어 누가 올린 곡인지 알 수 있습니다.
  • 마지막으로 부른 날 — 날짜가 있는 콘티에 들어간 곡은 "마지막으로 부른 날: 10월 25일 (일)"처럼 표시됩니다. 같은 곡을 너무 자주 부르지 않게 조절할 때 쓰세요.

내보내기 · 백업

  • ⬇ 엑셀 — 지금 보이는 곡 목록(검색·정렬·즐겨찾기 조건 그대로)을 엑셀에서 열 수 있는 파일(CSV)로 받습니다.
  • ⬇ 백업 — 지금 작업 공간의 곡과 콘티 전체를 백업 파일(JSON)로 받습니다.
  • 받은 파일 맨 위에는 저작권 안내 문구가 함께 들어갑니다.

⭐ 즐겨찾기

자주 부르는 곡, 내가 맡은 곡을 나만의 목록으로 따로 모아 둘 수 있습니다.

  1. 곡 제목 왼쪽의 ☆를 누르면 ★(노란 별)로 바뀌며 즐겨찾기에 들어갑니다. 다시 누르면 빠집니다.
  2. ★ 즐겨찾기만 버튼을 누르면 별 표시한 곡만 보입니다.
  3. 콘티에서 곡을 고를 때도 ★ 즐겨찾기만으로 바로 골라 담을 수 있습니다.
나만 보입니다 — 즐겨찾기는 사람마다 따로 저장됩니다. 팀 곡에 별을 달아도 다른 팀원 화면에는 표시되지 않고, 어느 기기에서 로그인해도 그대로 남아 있습니다.

📋 콘티 만들기

  1. 맨 위 작업 공간이 팀으로 되어 있는지 확인합니다. (팀원과 함께 볼 콘티라면)
  2. 콘티 탭에서 콘티 이름을 입력하고 예배 날짜를 고른 뒤 콘티 저장을 누릅니다. 날짜는 처음부터 다가오는 주일로 채워져 있습니다. 예: 11월 1주 주일예배
  3. 왼쪽 콘티 목록은 월별로 묶여 최근 날짜부터 보입니다(날짜 없는 콘티는 맨 아래 "날짜 없음"). 콘티를 누르면 오른쪽에 상세 화면이 열립니다.
  4. 아래 곡 추가에서 곡을 체크하고 선택한 곡 추가를 누릅니다. (곡 고르기 참고)
  5. 순서 바꾸기 — 콘티 순서의 곡을 마우스로 끌어 놓으면 순서가 바뀌고 바로 저장됩니다.

콘티 화면의 기능

  • 예배 날짜 바꾸기 — 콘티 이름 아래 예배 날짜를 바꾸면 바로 저장됩니다.
  • 📄 복제 — 지금 콘티를 그대로 복사해 새 콘티를 만듭니다. 곡 순서와 콘티별 Key·메모까지 복사되고, 날짜는 원래 날짜 + 7일(날짜가 없으면 다가오는 주일)로 정해집니다. 지난주 콘티를 고쳐 쓸 때 편합니다.
  • Key·메모 — 곡 옆 버튼을 누르면 이 콘티에서만 쓸 Key와 메모를 정할 수 있습니다. 곡 목록의 원래 정보는 바뀌지 않습니다. 바꾼 Key는 D ← C처럼(이번 Key ← 원래 Key) 표시되고, 카톡 요약·공유 화면·인쇄에 모두 반영됩니다. 원래대로를 누르면 되돌립니다.
  • 🖨 인쇄·PDF — 콘티 악보를 종이에 인쇄하거나 PDF 파일로 저장합니다. (인쇄 · PDF 저장)
  • 💬 카톡 요약 — 예배 날짜, 곡 순서·아티스트·Key(콘티별 Key 반영)·BPM·송폼·메모(공유 링크가 있으면 링크까지)를 카카오톡에 붙여 넣기 좋은 글로 복사합니다.
  • 🔗 공유 링크 — 로그인 없이 볼 수 있는 링크를 만듭니다. (공유 링크 참고)
  • ▶ 연속재생 — 콘티의 유튜브 영상을 차례로 이어서 재생합니다. 연습할 때 편합니다.
  • 연습 완료 체크 — 곡마다 체크해 두면 "연습 완료 3 / 5곡"처럼 진행 상황이 보이고, 다 하면 🎉가 나옵니다. 체크는 지금 쓰는 기기에만 저장됩니다.
  • ‹ 이전 · 다음 › — 공유 링크를 연 팀원들의 화면을 한 곡씩 넘깁니다. (예배 인도용)
  • 콘티에서 곡 빼기, 콘티 삭제도 할 수 있습니다. 팀 콘티는 만든 사람이나 팀장이 지울 수 있습니다.

🔎 콘티에 곡 고르기

콘티 상세 화면 아래 곡 추가에서 여러 곡을 한 번에 골라 담습니다.

  • 검색 — 제목·아티스트·코드 검색
  • 정렬 — 코드순 · 제목순 · 아티스트순
  • 코드별로 보기 — 코드순일 때 위에 전체 C 1 D 3 E 2 … 버튼이 나옵니다. 숫자는 그 코드의 곡 수입니다. 누르면 그 코드의 곡만 보이고, 다시 누르면 전체로 돌아갑니다. 코드가 없는 곡은 코드 없음에 모입니다.
  • 보기 방식 — 목록(한 줄씩 촘촘하게) / 카드(제목·아티스트·Key·BPM을 크게). 마지막에 고른 방식이 기억됩니다.
  • 칸 배치 — 컴퓨터에서는 3줄로 나란히, 태블릿은 2줄, 휴대폰은 목록 1줄 · 카드 2줄로 화면에 맞춰 바뀝니다.
  • ★ 즐겨찾기만 — 내가 별 표시한 곡만 보입니다. 곡 이름 옆 ☆를 눌러 여기서 바로 즐겨찾기할 수도 있습니다.
  • 여러 곡을 체크하면 버튼에 선택한 곡 추가 (3)처럼 개수가 표시됩니다.
같은 공간의 곡만 — 팀 콘티에는 팀 곡만, 개인 콘티에는 내 개인 곡만 담을 수 있습니다. 이미 콘티에 들어 있는 곡은 목록에 나오지 않습니다.

🖨 인쇄 · PDF 저장

콘티의 악보를 종이 한 장에 여러 곡씩 배치해 인쇄하거나, PDF 파일로 저장해 보관·전송할 수 있습니다.

  1. 콘티 상세 화면에서 🖨 인쇄·PDF를 누릅니다.
  2. 위쪽에서 고릅니다.
    • 용지 — A4 세로 · A4 가로 · Letter 세로
    • 한 장에 — A4 세로·Letter: 1 / 2 / 4곡, A4 가로: 1 / 2 / 3곡
    • 첫 장에 곡 순서 — 첫 장 맨 위에 곡 순서·Key·BPM 목록을 넣습니다.
    고른 설정은 다음에도 기억됩니다.
  3. 아래 미리보기를 확인하고 인쇄 / PDF로 저장을 누릅니다.
  4. 인쇄 창에서 프린터를 고르면 종이로, 대상을 "PDF로 저장"으로 고르면 PDF 파일로 받습니다. 여백은 없음, 배경 그래픽은 켜 두세요.
  • 각 장 맨 위에는 예배 날짜·콘티 이름과 쪽 번호가, 곡마다 번호·제목·Key(콘티별 Key 반영)와 메모가 표시됩니다.
  • 악보 이미지가 없는 곡은 "악보 이미지 없음"으로 표시되고, PDF 악보가 있으면 그 주소가 함께 적힙니다.
  • 모든 장 아래에 저작권 안내 문구가 함께 인쇄됩니다.
악보 인쇄·PDF는 복제에 해당합니다. 교회가 가진 사용 권한 범위 안에서만 쓰고, 단체 대화방·인터넷에 올리지 마세요.

🔗 공유 링크 · 예배 중 악보 넘기기

링크 만들고 보내기

  1. 콘티 상세 화면에서 🔗 공유 링크를 누르면 링크가 만들어집니다. 복사로 복사합니다.
  2. 악보 화면으로 바로 열리는 링크가 필요하면 악보만 링크를 복사합니다.
  3. 카카오톡·문자로 팀원에게 보냅니다. 받은 사람은 로그인 없이 바로 볼 수 있습니다.

🔒 공유 비밀번호 (선택)

  1. 공유 링크를 만든 뒤 아래 공유 비밀번호 칸에 숫자 6~8자리를 넣고 걸기를 누릅니다.
  2. 링크를 연 사람은 비밀번호를 넣어야 콘티를 볼 수 있습니다. 한 번 맞히면 그 창을 닫을 때까지 다시 묻지 않습니다.
  3. 바꾸기로 새 비밀번호를, 해제로 비밀번호 없이 되돌릴 수 있습니다.
  4. 한 기기에서 비밀번호를 5번 틀리면 그 기기만 15분 동안 잠깁니다. 다른 팀원의 휴대폰은 영향을 받지 않습니다. (여러 기기에서 합쳐 30번 넘게 틀리면 링크 전체가 잠기고, 반복될 때마다 잠금 시간이 15분 → 30분 → 1시간…으로 늘어납니다. 최대 24시간입니다.) 급하면 콘티 화면에서 비밀번호를 새로 걸면 잠금이 바로 풀립니다.
링크와 비밀번호는 따로 — 링크와 비밀번호를 같은 메시지에 보내면 효과가 줄어듭니다. 비밀번호는 팀원에게 따로 알려 주세요. 로그인한 팀원은 앱의 콘티 화면에서 비밀번호 없이 곡을 넘길 수 있습니다.

공유 화면 쓰는 법

  • 📋 전체 보기 — 곡 목록, 악보, 유튜브, MR, PDF, 메모가 모두 보이는 화면
  • 📄 악보만 — 악보만 크게 보여 주는 무대용 화면
  • 곡 넘기기 — 화살표 버튼을 누르거나, 휴대폰·태블릿에서는 악보를 좌우로 밀어서 넘깁니다.
  • 맞춤 · − · + — 악보 전체를 화면에 맞추거나 확대·축소합니다.
  • ⊞ 목록 — 여러 장 악보를 한눈에 보고 원하는 장으로 이동합니다.
  • 🎧 MR 열기 · 📄 PDF 열기 — 반주와 PDF 악보를 엽니다.
  • 화면 위에는 예배 날짜와 콘티 이름이, 맨 아래에는 저작권 안내가 표시됩니다. 콘티별 Key·메모도 그대로 보입니다.

실시간 동기화 (인도자가 넘기면 모두 함께)

  • 화면에 🔴 실시간 동기화 중이 보이면, 한 사람이 곡을 넘길 때 같은 링크를 연 모든 사람의 화면이 3초 안에 함께 넘어갑니다.
  • 예배 전에 팀원 모두 같은 링크에 들어와 첫 곡이 맞게 보이는지 한 번 확인하세요.
공유 링크(비밀번호를 걸었다면 비밀번호까지)를 아는 사람은 누구나 곡을 넘길 수 있습니다. 예배 중에는 인도자만 넘기도록 미리 약속하고, 링크는 팀원에게만 보내 주세요.

👥 팀 만들기 · 초대

팀장이 할 일

  1. 팀 탭에서 팀 이름을 입력하고 팀 만들기를 누릅니다. 만든 사람이 팀장이 됩니다.
  2. 팀 옆의 초대코드: XXXXXXXX를 누르면 복사됩니다. 팀원에게 보내 주세요.
  3. 이미 개인 공간에 곡·콘티를 많이 만들어 두었다면 내 곡·콘티를 이 팀으로 옮기기를 누르세요. 한 번에 팀 공간으로 옮겨져 팀원 모두가 보게 됩니다.

팀원이 할 일

  1. 회원가입·로그인 후 팀 탭의 초대 코드 입력 칸에 받은 코드를 넣고 팀 참여를 누릅니다.
  2. 맨 위 작업 공간에서 팀: (팀 이름)을 고르면 팀의 곡과 콘티가 보입니다.

팀 관리

  • 팀장의 팀 탭에는 팀원 목록이 보입니다.
  • 팀원이 비밀번호를 잊었다면 팀원 옆 비밀번호 초기화를 누릅니다. raon-xxxx-xxxx-xxxx 형태의 임시 비밀번호가 한 번만 나오니 팀원에게 직접 알려 주세요. (비밀번호 참고)
  • 팀원은 나가기로 팀을 떠날 수 있습니다. 팀원이 올린 팀 곡은 팀에 그대로 남습니다.
  • 팀장은 팀 삭제를 할 수 있습니다. 팀을 지워도 곡·콘티는 지워지지 않고 각자 만든 사람의 개인 공간으로 돌아갑니다.

🔑 비밀번호 · 계정

비밀번호 바꾸기

  1. 오른쪽 위 비밀번호 변경을 누릅니다.
  2. 현재 비밀번호, 새 비밀번호(6자 이상), 새 비밀번호 확인을 입력하고 변경을 누릅니다.

비밀번호를 잊었을 때

  1. 팀장에게 초기화를 요청합니다. 팀장이 팀 탭에서 비밀번호 초기화를 누르면 임시 비밀번호가 나옵니다.
  2. 팀장에게 받은 임시 비밀번호로 로그인하면 비밀번호 변경 창이 자동으로 열립니다. 현재 비밀번호 칸에 임시 비밀번호를, 새 비밀번호 칸에 앞으로 쓸 비밀번호를 넣고 바꿉니다.
  3. 비밀번호를 바꾸기 전에는 다른 기능을 쓸 수 없고, 임시 비밀번호는 24시간 뒤 만료됩니다. 만료되었다면 팀장에게 다시 요청하세요.
비밀번호(임시 비밀번호 포함)를 단체 대화방이나 화면 캡처로 공유하지 마세요. 꼭 본인에게만 직접 전달해 주세요.

❓ 자주 묻는 질문 · 문제 해결

팀원이 내가 올린 곡을 못 본다고 해요

맨 위 작업 공간이 내 개인 공간일 때 올린 곡은 나만 보입니다. 팀 탭의 내 곡·콘티를 이 팀으로 옮기기를 누르거나, 작업 공간을 팀으로 바꾼 뒤 다시 추가하세요. 팀원도 작업 공간을 팀으로 골라야 보입니다.

회원가입이 안 돼요

회원가입 버튼 아래 빨간 글씨를 확인하세요.

  • "이미 가입된 이메일입니다" — 예전에 가입한 적이 있는 이메일입니다. 이미 계정이 있어요 → 로그인을 눌러 로그인하세요. 비밀번호가 기억나지 않으면 팀장에게 비밀번호 초기화를 요청하세요.
  • "비밀번호는 6자 이상이어야 합니다" — 비밀번호를 6자 이상으로 정하세요.
  • "이메일 주소 형식이 올바르지 않습니다" — name@gmail.com처럼 @와 점(.)이 들어간 이메일을 넣으세요.
"이메일 또는 비밀번호가 맞지 않습니다"가 떠요

보기를 눌러 비밀번호를 확인하세요. 이메일은 대문자·앞뒤 공백과 상관없이 인식됩니다. 처음 오셨다면 회원가입을 먼저 해야 합니다. 그래도 안 되면 팀장에게 비밀번호 초기화를 요청하세요.

새 기능이 안 보이거나 화면이 이상해요

예전 화면이 브라우저에 남아 있는 경우입니다. 컴퓨터는 Cmd+Shift+R(윈도우는 Ctrl+Shift+R), 휴대폰은 브라우저를 닫았다가 다시 열어 주세요.

악보가 보이지 않아요
  • 곡의 악보 이미지 URL이 브라우저 주소창에서 그림으로 바로 열리는지 확인하세요. 웹페이지 주소가 아니라 이미지 파일 주소여야 합니다.
  • 콘티에 곡이 저장되었는지 확인하세요.
  • PDF 악보는 📄 PDF 열기로 엽니다.
삭제 버튼이 안 보여요

팀 곡은 팀장만 지울 수 있어서 팀원에게는 삭제 버튼이 보이지 않습니다. 지워야 할 곡이 있으면 팀장에게 말씀해 주세요.

예배 중에 화면이 같이 안 넘어가요

모두 같은 공유 링크를 열었는지, 화면에 🔴 실시간 동기화 중이 보이는지 확인하세요. 넘긴 뒤 최대 3초 정도 걸릴 수 있습니다. 인터넷이 약하면 늦어질 수 있으니 예배 전에 한 번 맞춰 보세요.

"악보 사진 올리기가 아직 설정되지 않았습니다"라고 나와요

교회 구글 드라이브 연결 설정이 끝나기 전에는 사진을 올릴 수 없습니다. 관리자에게 문의해 주세요. 그동안에는 악보 이미지 주소를 직접 넣어 쓰실 수 있습니다.

사진을 올렸는데 곡에 악보가 안 보여요

사진을 올린 뒤 곡 저장(수정 중이면 저장)을 눌렀는지 확인하세요. 저장해야 곡에 반영됩니다.

공유 링크를 열었더니 비밀번호를 물어요

공유한 분이 공유 비밀번호를 걸어 둔 콘티입니다. 받은 숫자 비밀번호를 넣으세요. 모르면 공유한 분에게 물어보세요. "15분 동안 잠겼습니다"가 나오면 그 기기에서 비밀번호를 여러 번 틀린 것입니다. 잠시 뒤 다시 시도하거나, 공유한 분에게 비밀번호를 새로 걸어 달라고 하세요.

인쇄했더니 악보가 잘리거나 여백이 생겨요

인쇄 창에서 여백을 없음으로, 배율은 기본(100%)으로 두세요. 용지 방향(세로/가로)이 앱에서 고른 용지와 같은지도 확인하세요.

찾는 곡이 목록에 없어요

곡 목록은 하루 30곡씩 업데이트될 예정입니다. 바로 필요하면 곡 추가 방법대로 직접 등록하세요(팀과 함께 쓸 곡은 팀 공간에).
